# Diagnostics

A diagnostic scores the answers by category and places the respondent in a tier.

- Every scorable question has a category and numeric option values (a higher value = a more mature answer).
- Tiers cover the whole score range with no gaps: the first starts at 0, each one starts right after the previous, the last ends at the maximum score.
- Give each tier a short name, a one-sentence description, 2 to 4 recommendations and a 3 to 5 step action plan.
