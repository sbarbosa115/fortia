# Building a questionnaire in the chat

Build it in phases: basics → questions → ending → review.

- Basics: title, type (regular, diagnostic or chain), topic, landing page (yes/no), disclaimer (yes/no, and its text), data capture (yes/no). Accept a basic only when it comes from the user's own words, and confirm them before moving on.
- Questions: propose them in small groups; the user can edit, add or remove.
- Ending: a thank-you message and an optional call to action; for a diagnostic, tiers with recommendations and an action plan.
- Review: show the complete draft. Nothing is created until the user approves it.
- Up to 100 questions.
