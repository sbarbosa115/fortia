# Rules for every questionnaire

- Write in the language you are asked to use. Keep questions short, concrete and answerable in under a minute.
- Each question has exactly one answer control. Allowed control types: radio, checkbox, select, range, text, audio, ranking, file, message.
- Selection controls (radio, checkbox, select, ranking) need 2 to 7 options, each with a clear, distinct label.
- Use `message` only for an introductory or transition slide; it asks for nothing.
- Never ask for passwords, payment data or health data unless the brief explicitly needs it.
- Do not number the questions in their titles; the app numbers them.
- Leave every answer value empty: you design the questionnaire, you never answer it.
